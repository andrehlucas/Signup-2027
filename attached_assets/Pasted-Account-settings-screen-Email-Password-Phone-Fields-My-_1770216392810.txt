Fields

	•	Enter your new company name (input)
	•	Submit (button)

Warning / requirement details shown
	•	Instruction: “To update your business name, please submit a name change request below.”
	•	Fee notice: A one-time fee of $30 will apply for the update.
	•	A red asterisk indicator appears beside the instruction line (implying an important/required notice).

How the customization experience should be (recommended UX behavior)

1) Clear “view vs edit” states
	•	Show current values (email/phone/company name) in a read-only state with an Edit action.
	•	When editing starts, switch that section into an “editing” state (inputs appear + Save/Cancel).

2) Inline validation and smart button states
	•	Disable “Update Password” until:
	•	current password is entered
	•	new password meets requirements
	•	confirm password matches
	•	Show live checklist under the new password field:
	•	✅ 8+ characters
	•	✅ 1 uppercase
	•	✅ 1 number
	•	✅ 1 symbol
	•	For phone: validate format (and country code if needed) + show an example like “(555) 555-5555”.

3) Safer email change flow
	•	Clicking Change Email should open a small modal/step flow:
	1.	Enter new email
	2.	Confirm password (or 2FA)
	3.	“We sent a verification link/code to the new email”
	4.	Success state updates the displayed email after verification

4) Company name change should confirm cost + reduce surprises
	•	Before submitting:
	•	Require a checkbox: “I understand there is a $30 one-time fee.”
	•	Optional: show why (admin verification, billing records, receptionist scripts, etc.)
	•	After clicking Submit:
	•	Confirmation modal: “Submit name change request for [New Name] and accept $30 fee?”
	•	Provide expected processing time/status: “Pending review” + where to track it.

5) Strong feedback and error handling
	•	After any action: show a clear success toast (“Password updated”, “Phone updated”, “Request submitted”).
	•	If error: show specific messages (not generic):
	•	“Current password is incorrect”
	•	“Passwords don’t match”
	•	“Phone number invalid”
	•	“Company name cannot be empty”

6) Consistent help placement
	•	Keep the How-to Video link near the section header and add short helper text like:
	•	“Need help? Watch how to submit a company name change.”
