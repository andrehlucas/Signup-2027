---
name: Mobile stepper policy
description: Scope and navigation intent for the compact enrollment progress header.
---

Use the compact current-step header on mobile only; keep the full four-step desktop navigation.

**Why:** The user approved the compact stepper specifically “but only for mobile,” to reduce its vertical footprint.

**How to apply:** Keep the current step name, step count and thin progress segments visible, with a menu for returning to completed steps. Future steps remain unavailable. Returning to the location step means the saved office confirmation, not a fresh location search. Preserve the desktop layout and existing footer animation when refining this mobile navigation.
