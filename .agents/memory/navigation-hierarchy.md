Back must remain a text-only action, not a filled primary button, on the location and program steps.

**Why:** The user explicitly rejected converting Back to a filled button during the navigation color update and chose to restore its original style.

**How to apply:** Apply filled-button color changes to Continue without changing Back's hierarchy. Keep the same distinction in the app and its design preview.
