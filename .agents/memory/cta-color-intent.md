---
name: CTA color intent
description: What the user means by brand-color enrollment buttons.
---

For enrollment CTA buttons, “brand color with white text” means the bright cyan brand blue, not charcoal or a dark teal substitute.

**Why:** The user said the button still looked dark after a darker blue was substituted for the requested brand color.

**How to apply:** Use the shared bright brand action color consistently for signup and bundle-modal CTAs. Do not silently darken the default fill for contrast; explain that tradeoff if revisiting accessibility.
