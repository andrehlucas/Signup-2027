---
name: Add-on preview readability
description: Intent behind optional add-on cards, included-feature pills and complete-card disclosure.
---

Optional add-ons use two columns where readable, with two-line description previews and an independent Read more/Show less disclosure. Reading details must not select or purchase an add-on.

**Why:** The user requested a two-column design with visible descriptions and click-to-read-more.

**How to apply:** Keep phone layouts readable with a single column. When shortening the overall catalog, show complete cards and a Show all control rather than a fixed-height crop or fading overlay: descriptions have variable heights, and cropping can hide actionable buttons or expanded text.

Keep optional add-ons in this priority order: Callout, Custom Business Email, Supervised Transfer, Message Taking, Appointment Scheduling, omitting any already included in the selected bundle.

**Why:** The user requested this order, then explicitly replaced included-service cards with a compact summary to distinguish included services from optional purchases.

**How to apply:** Put each included add-on name in its own pill between the blurb and optional cards, labeled “Included on {bundle}:”, without descriptions or purchase controls. On mobile, put the label above wrapping pills with readable 16px text and show an “Optional add-ons” heading before the paid cards; every included name must be visible without horizontal scrolling or truncation. Keep the existing single-line desktop presentation. Omit the included summary when nothing is included. Keep included services out of both the initial and expanded optional grid. Round an odd initial optional preview up with the next real optional service when available; Show all must expose every optional service even when that produces an odd total. Never duplicate or invent cards to fill a row. Inclusion comes from the selected bundle, not an add-on's default price.

**Why mobile differs:** The user found the scrolling pill row difficult to read and approved a mobile-only wrapping layout with the bundle label on its own line and clearer separation from optional purchases.

Additional Extensions is no longer offered in enrollment. Customize's additional phone services panel is for the selected toll-free number only, not the primary local business number.

**Why:** The user explicitly requested removing Additional Extensions after previously separating phone extras from the primary number.

**How to apply:** Keep the primary local number in the order summary and its selection on plan review. Hide the extra-services panel when no toll-free number is selected or included. Never reintroduce extension controls or charges from an older draft; preserve the customer's other selections.
